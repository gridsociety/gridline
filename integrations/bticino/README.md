# BTicino — integrazione pianificata

Questa cartella è il punto di ingresso per il contributo successivo.
Il backend non è ancora eseguibile in questa versione di Gridline.

Seguire [il passaggio di consegne](../../docs/BTICINO-HANDOFF.md).
Il contributo dovrà dichiarare applicazione/versione, operazioni MCP realmente
provate, requisiti, autenticazione, formato nativo, generazione dei dettagli
per componente e passaggio a Documentor, con una demo pubblica sintetica.
