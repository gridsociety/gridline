# Provenienza e contenuti distribuiti

Gridline deriva dal toolkit aziendale `single-line-diagrams` 1.0.1,
repository Grid Society grid-standards, commit
`fba2b476783df1db02a07b41969214567eba4b81`.
Il codice del compositore e del server MCP conserva questa provenienza.

Il template a sezioni dirette incorpora le correzioni di impaginazione del
successivo caso aziendale: dimensioni pagina esplicite, nessuna cornice HTML
aggiuntiva, interruzione dopo l'ultima sezione corretta. Non contiene dati della
commessa. Logo e cartiglio appartengono a Grid Society.

I simboli derivati dalla collezione QElectroTech sono attribuiti nei file e in
`src/gridline/resources/symbols/manifest.json`; il testo di licenza originale è
in `QET-Elements.LICENSE`. Fonte:
https://github.com/qelectrotech/qelectrotech-elements/blob/main/ELEMENTS.LICENSE
Le variazioni di scala storiche sono dichiarate nei simboli. MT e RCBO sono
copie non modificate dalla collezione installata, con percorso e hash nel manifest.
Gli adattamenti storici da documentazione del committente non sono inclusi.

Documentor è una dipendenza proprietaria Grid Society, installata separatamente;
il suo codice e la sua cronologia non sono ripubblicati qui. Le dipendenze Python
restano soggette alle rispettive licenze; il lock registra le versioni.

Questo primo rilascio non attribuisce una nuova licenza open source al codice
aziendale. La visibilità pubblica del repository e le licenze dei materiali
inclusi sono aspetti distinti. Per utilizzi esterni del codice o del marchio
fare riferimento a Grid Society e alle licenze dei singoli contenuti.
